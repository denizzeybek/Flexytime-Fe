# strip-comments (FE)

Bulk-removes decorative comments from the FE checkout. The codebase accumulates "what does this do" narration over time; this skill clears it in one pass so the rules + hook can keep the floor clean afterwards.

## When to use this skill

- A branch / PR review surfaces dozens of decorative comments and the user asks to clean them up.
- A new contributor has been pasting their notes into source; you want to reset the surface in one sweep.
- The `comment-policy.md` rule was tightened (only TODO survives) and the existing code needs to catch up.

## When NOT to use this skill

- A single file has a couple of bad comments — use `Edit` directly, the skill is overkill.
- You want to add comment rules without stripping yet — edit `comment-policy.md` alone.
- The repo has generated code under `src/client/` — those files carry the codegen banner, **do not touch them** (the script must skip).

## What survives

A comment is kept iff its first non-space character (after `//` or inside `/* */`) matches one of:

- `TODO`, `FIXME`, `HACK` (case-insensitive). These are the only **content** comments allowed.
- `eslint-disable*`, `eslint-enable*`, `eslint-disable-next-line`, `eslint-disable-line`.
- `@ts-expect-error`, `@ts-ignore`, `@ts-nocheck`.
- `prettier-ignore`, `prettier-ignore-start`, `prettier-ignore-end`.
- `/// <reference ... />` (only in `.d.ts` files; triple-slash, not double).
- `/* generated using openapi-typescript-codegen -- do not edit */` and the rest of the codegen banner (skip the whole file via the path filter, not the content filter).

Anything else — single line `//`, block `/* */`, JSDoc `/** */`, Vue `<!-- -->` inside `<template>` — is removed.

## Files in scope

```
src/**/*.{ts,tsx,js,jsx,vue,scss,css}
```

Hard exclusions (never edit):

- `src/client/**` (generated by `yarn gcl` — see state-services.md "Regeneration").
- `node_modules/**`, `dist/**`, `coverage/**`, `.yarn/**`.
- `*.d.ts` files that are pure declaration shims (the `/// <reference />` directives in them are tool directives, not comments; they stay).

## The procedure

### 1. Read the latest `comment-policy.md`

Confirm the allow-list above still matches `/Users/denizzeybek/Documents/flexytime-fe/.claude/rules/comment-policy.md`. If the rule has tightened further (e.g. only `TODO` and no `FIXME`/`HACK`), match the rule, not this skill text.

### 2. Run the stripper

Use `node` with a small inline script that uses a string/regex state machine so we don't strip inside strings, template literals, or regex. The script:

- Walks files matching the in-scope glob.
- For each file, tokenises just enough to know "we're inside a string / template / regex / comment".
- When it sees a comment open (`//`, `/*`, or inside `<template>` a `<!--`), it captures the comment, runs the allow-list check, and either keeps or deletes it.
- Preserves the surrounding whitespace exactly (no aggressive reflow — let Prettier do the formatting pass at the end).

Paste this into a temp file and run it; it is intentionally written to be re-runnable / idempotent:

```bash
cat > /tmp/strip-comments-fe.mjs <<'JS'
import { readFileSync, writeFileSync, statSync } from 'node:fs';
import { execSync } from 'node:child_process';

const KEEP_RE = /^\s*(TODO|FIXME|HACK|eslint-(disable|enable)|@ts-(expect-error|ignore|nocheck)|prettier-ignore)/i;
const TRIPLE_SLASH_RE = /^\/\s*<reference\s/;
const CODEGEN_RE = /generated using openapi-typescript-codegen/;

const files = execSync(
  "git ls-files 'src/**/*.ts' 'src/**/*.tsx' 'src/**/*.js' 'src/**/*.jsx' 'src/**/*.vue' 'src/**/*.scss' 'src/**/*.css' | grep -v '^src/client/'",
  { encoding: 'utf8' },
).trim().split('\n').filter(Boolean);

const stripJs = (src) => {
  let out = '';
  let i = 0;
  const n = src.length;
  while (i < n) {
    const c = src[i], d = src[i + 1];
    if (c === '"' || c === "'" || c === '`') {
      const quote = c;
      let j = i + 1;
      out += c;
      while (j < n) {
        if (src[j] === '\\') { out += src[j] + src[j + 1]; j += 2; continue; }
        if (quote === '`' && src[j] === '$' && src[j + 1] === '{') {
          out += '${';
          j += 2;
          let depth = 1;
          while (j < n && depth > 0) {
            if (src[j] === '{') depth++;
            else if (src[j] === '}') depth--;
            if (depth === 0) break;
            out += src[j++];
          }
          continue;
        }
        out += src[j];
        if (src[j] === quote) { j++; break; }
        j++;
      }
      i = j;
      continue;
    }
    if (c === '/' && d === '/') {
      let j = i + 2;
      while (j < n && src[j] !== '\n') j++;
      const body = src.slice(i + 2, j);
      const keep = KEEP_RE.test(body) || TRIPLE_SLASH_RE.test(body) || CODEGEN_RE.test(body);
      if (keep) out += src.slice(i, j);
      else {
        let k = out.length - 1;
        while (k >= 0 && (out[k] === ' ' || out[k] === '\t')) k--;
        out = out.slice(0, k + 1);
        if (out[out.length - 1] !== '\n' && j < n) { /* keep line */ }
      }
      i = j;
      continue;
    }
    if (c === '/' && d === '*') {
      let j = i + 2;
      while (j < n - 1 && !(src[j] === '*' && src[j + 1] === '/')) j++;
      j += 2;
      const body = src.slice(i + 2, j - 2);
      const keep = KEEP_RE.test(body) || CODEGEN_RE.test(body);
      if (keep) out += src.slice(i, j);
      i = j;
      continue;
    }
    out += c;
    i++;
  }
  return out
    .split('\n')
    .map(line => line.replace(/[ \t]+$/, ''))
    .join('\n')
    .replace(/\n{3,}/g, '\n\n');
};

const stripVue = (src) => {
  const tplRe = /<template[^>]*>[\s\S]*?<\/template>/g;
  src = src.replace(tplRe, (block) => block.replace(/<!--[\s\S]*?-->/g, ''));
  const scriptRe = /(<script[^>]*>)([\s\S]*?)(<\/script>)/g;
  src = src.replace(scriptRe, (_, open, body, close) => open + stripJs(body) + close);
  const styleRe = /(<style[^>]*>)([\s\S]*?)(<\/style>)/g;
  src = src.replace(styleRe, (_, open, body, close) => open + stripJs(body) + close);
  return src;
};

let touched = 0;
for (const path of files) {
  try {
    statSync(path);
  } catch { continue; }
  const before = readFileSync(path, 'utf8');
  const after = path.endsWith('.vue') ? stripVue(before) : stripJs(before);
  if (after !== before) {
    writeFileSync(path, after);
    touched++;
  }
}
console.log(`stripped ${touched} file(s)`);
JS
node /tmp/strip-comments-fe.mjs
```

### 3. Formatting + lint

After stripping, run:

```bash
yarn format
yarn lint
yarn type-check
yarn build
```

If `lint` finds new violations (e.g. `// eslint-disable-...` that had its `-- reason` consumed because the `--` looked like a comment fragment), open the file and restore manually. Comment removal can never make a previously-passing build fail; if it does, restore the comment with `// TODO: ...` so it survives the next pass.

### 4. Commit

One commit per repo:

```
chore(comments): strip non-TODO comments

Run /strip-comments. Decorative narration removed across src/ except for
TODO/FIXME/HACK markers and tool directives (eslint-, @ts-, prettier-,
triple-slash references). Generated client (src/client/) untouched.

Follow-up enforcement lives in `.claude/rules/comment-policy.md` and the
no-comment-noise hook (existing).

Co-Authored-By: Claude Opus 4.7 <noreply@anthropic.com>
```

## Don't

- ❌ Strip files under `src/client/` (regenerated by `yarn gcl`; the banner must stay so future runs notice the file is generated).
- ❌ Restore comments that were "explanatory" without converting them to `// TODO:` with a real next step.
- ❌ Run the script across `node_modules/`, `dist/`, or any vendored folder.
- ❌ Add a wholesale `// eslint-disable max-comments` or anything like it to suppress the hook — the hook is the source of truth.

## After-effects

Once this skill has been run for the first time, the `no-comment-noise` PreToolUse hook keeps the floor clean — new violations are blocked at write time. If you find the hook is annoying on a legitimate exception, the answer is to add a `// TODO:` (which the hook allows) with a follow-up plan, not to weaken the rule.
